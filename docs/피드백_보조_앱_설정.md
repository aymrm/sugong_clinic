# 피드백 보조 앱 설정 안내

기본 주소(`/`)가 새 피드백 보조 앱입니다. 예전 클리닉실 관리 화면은 `/clinic`(관리자용), `/clinic/teacher`(선생님용)로 옮겼습니다.

## 1. 데이터베이스 (한 번만)

Supabase 대시보드 → SQL Editor에서 순서대로 실행합니다.

1. `supabase/schema.sql` (이미 실행했다면 건너뜀)
2. `supabase/feedback_schema.sql`

`feedback_schema.sql`은 여러 번 실행해도 안전합니다. 하는 일:

- 새 표: 수업일 기록, 주간 피드백·리포트, 지난 피드백, 학생·학부모 메모, 상담 기록·제안, 학습지 분석, 정답지, 학교·연도별 특징, 시험지(학교 내신·모의고사·수능)와 문항 분석, 문제집, 교육과정(15·22개정)·과목·풀이 규칙, 추천 기록, 학원 설정
- 기존 표 보강: 학생에 담임·학교·목표 트랙·교육과정, 선생님에 주 시작 요일·리포트 표기 이름
- 권한: 학생에 딸린 정보(기록·피드백·메모·상담·학습지)는 **그 학생의 담임·담당 선생님·관리자만** 보고 고칠 수 있습니다. 학교·시험지·문제집·교육과정은 선생님 모두가 같이 씁니다.
- 사진 저장소 `fb-images`(비공개)를 만듭니다.
- 교육과정은 확인된 내용만 기본값으로 넣었습니다(2022 개정 과목명 변경, 2028 수능 범위, 선생님이 알려준 기하·덧셈정리 규칙). 나머지는 앱의 AI 도우미에게 말로 알려주면 채워집니다.

## 2. AI 기능 (Edge Function)

AI 기능은 Supabase 안의 작은 서버 함수(`ai`)가 처리합니다. 브라우저에서 대시보드로 올리는 방법이 가장 쉽습니다.

### 방법 A: 대시보드에서 (추천, 설치 필요 없음)

1. [Claude Console](https://console.anthropic.com) → API Keys에서 키를 만들고 복사합니다(`sk-ant-`로 시작). 결제 수단 등록이 필요합니다.
2. Supabase 대시보드 → 프로젝트 → 왼쪽 **Edge Functions** → **Secrets**에서 Key `ANTHROPIC_API_KEY`, Value에 복사한 키를 넣고 **Save**.
3. **Edge Functions** → **Deploy a new function** → **Via Editor**.
4. 함수 이름을 정확히 **`ai`** 로 정하고, 편집기 내용을 모두 지운 뒤 `supabase/functions/ai/index.ts` 파일 내용을 통째로 붙여넣습니다.
5. **Deploy function**을 누르고 성공 메시지를 기다립니다(10~30초).
6. 앱에서 피드백 탭의 **AI 초안 만들기**를 눌러 확인합니다.

코드를 고친 뒤에는 같은 함수를 열어 내용을 바꾸고 **Deploy updates**를 누르면 됩니다.

### 방법 B: 터미널(Supabase CLI)

컴퓨터에 [Supabase CLI](https://supabase.com/docs/guides/cli)를 설치한 뒤 저장소 폴더에서:

```bash
supabase login                                   # 브라우저가 열리면 로그인
supabase link --project-ref <프로젝트 ID>          # 대시보드 주소 /project/ 뒤의 글자
supabase secrets set ANTHROPIC_API_KEY=sk-ant-...  # Claude API 키 저장
supabase functions deploy ai                     # 함수 올리기
```

### 공통

- API 키는 서버에만 있고 브라우저로는 가지 않습니다.
- 기본 모델: 글쓰기 `claude-sonnet-5-5`, 사진 분석 `claude-opus-5-5`. 바꾸려면 Secrets에 `ANTHROPIC_MODEL_TEXT`, `ANTHROPIC_MODEL_VISION`을 추가하세요.
- AI로 보내기 전에 학생 이름·학교 이름은 가립니다. 단, 학습지·시험지 **사진 자체**는 그대로 전송됩니다.
- 안 될 때: Edge Functions → `ai` → **Logs**에서 오류 메시지를 확인하세요. "ANTHROPIC_API_KEY가 설정되지 않았어요"면 2단계를, "AI 호출 실패 (401)"이면 키를 다시 확인하세요.

## 3. 배포

새로 설치할 패키지는 없습니다. 지금처럼 GitHub에 올리면 Netlify가 자동으로 배포합니다(`public/_redirects`가 이미 있어 `/clinic` 같은 주소도 열립니다). Pull Request를 만들면 Netlify가 미리보기 주소(Deploy Preview)를 만들어 주므로, 확인한 뒤 `main`에 합치세요.

## 4. 처음 쓰기

1. 관리자 계정으로 로그인 → 내 학생 화면 오른쪽 위 ⚙️ → **학생·반** 탭
2. **명단 붙여넣기**: 엑셀에서 `이름 | 학교 | 학년 | 반 | 담임` 순서의 표를 복사해 붙여넣기. 반이 여러 개면 `/`로 나누고 과목은 `반이름:과목`
3. 반 목록에서 반마다 담당 선생님 지정 → 담임 반이 메인, 나머지는 서브 과목이 됩니다
4. **학원** 탭에서 학원 이름·캠퍼스(리포트 머리글), 채점 표시 규칙, 원문 저장 여부 설정
5. 다른 선생님은 가입 후 이름만 입력하면 됩니다(배정된 학생만 보입니다)

## 5. 화면

| 탭 | 하는 일 |
| --- | --- |
| 내 학생 | 이번 주 담임·서브 학생과 진행 상태. 학생을 누르면 수업 기록 → 피드백(AI 초안) → 리포트(담임) |
| 학습지 | 풀이 사진 업로드 → 문제별 요약 칸, 누르면 판단 근거. 확인을 마친 것만 피드백 초안에 쓰입니다 |
| 상담 | 점수 하락·출결·과제·상담 공백·시험 임박·반복 약점 조건에 걸린 학생과 AI 상담 대본 |
| 시험·교재 | 학교 연도별 특징, 시험지 분석(내신·모의고사·수능), 경향 비교, 문제집, 교육과정·풀이 규칙 |
| AI 도우미 | 말이나 사진으로 알려주면 DB에 맞게 정리해 변경을 제안 → [저장]을 눌러야 반영 |

**개선 요청함** (설정 → 개선 요청): 선생님 요청 중 지금 DB 구조나 앱 기능으로는 해결이 안 되는 것이 쌓입니다. AI 도우미는 맞는 칸이 없을 때 엉뚱한 곳에 억지로 넣지 않고 여기에 요청을 남기고, 같은 요청이 반복되면 횟수(×N)만 올립니다. 선생님이 직접 남길 수도 있습니다. 관리자는 상태(새 요청/검토 중/반영함/보류)를 바꾸고, **[N건 복사]**로 처리 전 요청을 정리된 글로 복사해 Claude에게 붙여넣으면 바로 반영 작업을 시작할 수 있습니다.

상담 추천 기준값은 `src/fb/pages/Counseling.jsx`의 `RULES`에서 바꿀 수 있습니다.

## 6. 알아둘 점

- 시험지·문제집 원문 저장은 기본으로 **켜져 있습니다**. 저작권 검토 결과에 따라 설정 → 학원 → "원문 텍스트 저장"을 끄면 이후로는 분석 정보만 저장됩니다(이미 저장된 원문은 따로 지워야 합니다).
- 학습지 사진 보관 기간 설정은 값만 저장되고, 자동 삭제는 아직 구현하지 않았습니다.
- 학습지·시험지 분석은 한 번에 1~3분 걸립니다. 화면을 나가도 서버에서 계속 진행됩니다.
