# 클리닉실 관리 — 선생님용 앱 설치 안내

선생님들께 이 문서를 그대로 보내드리면 됩니다. 한 번만 설치해두면 이후에는 홈 화면(또는 바탕화면)의 아이콘을 눌러서 일반 앱처럼 바로 열 수 있어요.

**접속 주소: `https://[사이트 주소]/teacher`**
(관리자용 사이트와는 다른 주소예요. 뒤에 `/teacher`가 꼭 붙어야 합니다.)

설치하지 않고 그냥 위 주소를 브라우저에서 열어서 써도 되지만, 설치해두면 매번 주소를 치거나 즐겨찾기를 찾을 필요 없이 아이콘 하나로 바로 켤 수 있어서 훨씬 편해요.

---

## 📱 아이폰 · 아이패드 (iOS / iPadOS)

> ⚠️ **꼭 "Safari" 앱으로 열어야 해요.** 카카오톡이나 문자로 받은 링크를 그냥 누르면 카카오톡 안의 브라우저로 열리는데, 이 경우 설치 메뉴가 안 나와요. 반드시 Safari 앱을 직접 켜서 주소를 입력해주세요.

1. **Safari** 앱을 엽니다.
2. 주소창에 `https://[사이트 주소]/teacher`를 입력해서 접속합니다.
3. 화면 아래(또는 위)에 있는 **공유 버튼**( 사각형에 위로 화살표 모양, ⬆️ )을 누릅니다.
4. 아래로 스크롤해서 **"홈 화면에 추가"**를 누릅니다.
5. 이름을 확인하고 (원하면 수정 가능) 오른쪽 위 **"추가"**를 누릅니다.
6. 홈 화면에 생긴 아이콘을 누르면 브라우저 주소창 없이 앱처럼 바로 열립니다.

카카오톡 링크로 받았다면: 링크를 길게 눌러 **"Safari로 열기"**를 먼저 선택한 다음 위 2~6번을 진행해주세요.

---

## 🤖 안드로이드 (갤럭시 등)

1. **Chrome** 앱으로 `https://[사이트 주소]/teacher`에 접속합니다.
2. 화면 아래쪽에 **"앱 설치"** 또는 **"홈 화면에 추가"** 배너가 자동으로 뜨면 바로 눌러줍니다.
   - 배너가 안 뜨면: 오른쪽 위 **점 3개(⋮) 메뉴** → **"앱 설치"** (또는 "홈 화면에 추가")를 눌러주세요.
3. 설치 확인 창에서 **"설치"**를 누릅니다.
4. 홈 화면이나 앱 목록에 생긴 아이콘을 누르면 바로 실행됩니다.

---

## 💻 맥 (Mac) — Safari

1. **Safari**로 `https://[사이트 주소]/teacher`에 접속합니다.
2. 위쪽 메뉴에서 **파일 → Dock에 추가...** 를 누릅니다. (또는 공유 버튼 → "Dock에 추가")
3. Dock에 생긴 아이콘을 누르면 독립된 창으로 바로 열립니다.

## 💻 맥 · 윈도우 — Chrome / Edge

1. **Chrome** 또는 **Edge**로 `https://[사이트 주소]/teacher`에 접속합니다.
2. 주소창 오른쪽 끝에 있는 **설치 아이콘**(⊕ 또는 모니터 모양)을 클릭합니다.
   - 안 보이면: 오른쪽 위 **점 3개(⋮) 메뉴** → **"앱 설치"**를 눌러주세요.
3. 설치 확인 창에서 **"설치"**를 클릭합니다.
4. 바탕화면 또는 시작 메뉴(윈도우) / Launchpad(맥)에 생긴 아이콘으로 실행합니다.

---

## 처음 열었을 때

설치 후 처음 열면 로그인 화면이 나옵니다. **관리자용 사이트와 똑같은 아이디/비밀번호**로 로그인하면 됩니다. 계정이 아직 없다면 "회원가입"으로 아이디(영문/숫자)와 비밀번호를 만들고, 처음 로그인 시 화면에 표시될 이름(예: "김도윤 T")을 한 번 입력해주세요.

## 자주 묻는 질문

**Q. 설치 안 하고 그냥 브라우저로 써도 되나요?**
네, 됩니다. 매번 주소를 열어야 하는 번거로움만 있을 뿐 기능은 동일해요.

**Q. 아이폰에서 "홈 화면에 추가"가 안 보여요.**
Safari가 아닌 다른 앱(카카오톡, 크롬 등) 안에서 링크를 열었을 가능성이 높아요. Safari 앱을 직접 켜서 주소를 입력해 접속해보세요.

**Q. 로그인이 안 돼요 / 비밀번호를 잊었어요.**
비밀번호 재설정은 이 앱에서 이메일로 보내드리는 방식이 아니라, 관리자가 직접 처리해드려야 해요. 클리닉실 관리자에게 문의해주세요.

**Q. 아이콘을 지우면 데이터도 지워지나요?**
아니요. 홈 화면 아이콘은 그냥 바로가기일 뿐이라, 지워도 데이터에는 전혀 영향이 없어요. 같은 주소로 다시 접속하면 그대로 이어집니다.
